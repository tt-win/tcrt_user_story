## Purpose

User Story Map canvas layout authority and coordinate write rules: load-time health assessment, collapse-consistent whole-tree layout, single-frame coordinate writes, new-node/import coordinate sources, and display-update termination.

## Requirements

### Requirement: 載入時的排版權威

載入 User Story Map 時，系統 SHALL 對資料庫既有座標評估健康度，並依結果決定顯示座標的來源。系統 MUST NOT 單以「座標存在且非 0」認定使用者已手動排版。

健康度評估 MUST 以節點盒 200×110（與畫布節點實際佔位一致）計算，並 MUST 由 `parent_id` 鏈推導節點深度，MUST NOT 採信節點上儲存的 `level` 欄位；深度推導 MUST 對自環與循環父子關係安全終止，無法連回根節點者視為深度 0。

判定 MUST 包含下列兩項，任一成立即為「不健康」：

- **TB 指紋**：節點數 ≥ 3、樹深 ≥ 2，且 ≥90% 的節點滿足 `position_y == 250 + depth × 100`（容差 0.01）。
- **重疊比例**：涉入至少一次節點盒重疊（`|Δx| < 200` 且 `|Δy| < 110`）的節點數佔比 ≥ 20%。

判定為不健康時，系統 MUST 以樹狀自動排版取代顯示座標，並 MUST 向使用者顯示「已改用自動排版顯示、尚未寫入」的通知。重疊比例大於 0 但小於 20% 且無 TB 指紋時，系統 MUST 沿用既有座標並 MUST 僅顯示可關閉的提示，MUST NOT 自動重排。兩項皆不成立時 MUST 沿用既有座標且不顯示提示。

#### Scenario: 層級往下堆疊的地圖恢復左右樹狀

- **WHEN** 使用者開啟一張所有節點皆符合 `position_y = 250 + depth × 100` 的地圖
- **THEN** 畫布 MUST 顯示自動樹狀排版的結果（同一深度的節點位於同一垂直欄、由左至右展開）
- **AND** 系統 MUST 顯示「已改用自動排版顯示」的通知
- **AND** 資料庫中的節點座標 MUST 維持不變

#### Scenario: 健康的手動排版不被更動

- **WHEN** 使用者開啟一張無 TB 指紋且無任何節點盒重疊的地圖
- **THEN** 畫布 MUST 使用資料庫既有座標
- **AND** MUST NOT 顯示排版提示

#### Scenario: 輕微重疊只提示不重排

- **WHEN** 使用者開啟一張重疊節點比例大於 0 且小於 20% 的地圖
- **THEN** 畫布 MUST 使用資料庫既有座標
- **AND** MUST 顯示可關閉的重疊提示，並提供觸發自動排版的入口

#### Scenario: 深度推導不採信 level 欄位且不被循環吊死

- **WHEN** 地圖中存在 `level` 欄位與實際父子深度不符的節點，或存在父節點指向自己的節點
- **THEN** 健康度評估 MUST 以 `parent_id` 鏈推導的深度為準並正常完成
- **AND** MUST NOT 進入無窮迴圈

#### Scenario: 重新整理即回到資料庫原狀

- **WHEN** 一張被判定為不健康的地圖以自動排版顯示後，使用者未採用該排版即重新整理頁面
- **THEN** 系統 MUST 再次以相同判定與相同輸入產生相同的顯示結果
- **AND** 資料庫座標 MUST 與重新整理前完全相同

### Requirement: 收合狀態下的整樹一致排版

任何一次自動排版 SHALL 為整棵樹產生單一世代的座標。被收合而隱藏的節點 MUST 由同一次排版結果推導座標（貼齊其最近的可見祖先），MUST NOT 保留前一世代的座標；以定錨節點對齊畫面的平移 MUST 套用到所有節點，包含隱藏節點。

排版結果 MUST 為 `(樹結構, 收合節點集合)` 的純函式：相同輸入 MUST 產生相同座標，MUST NOT 相依於先前的收合／展開歷程。

#### Scenario: 收合後可見節點緊湊且不留空洞

- **WHEN** 地圖載入時預設收合所有含 user story 子節點的父節點
- **THEN** 可見節點 MUST 依收合後的結構緊湊排列
- **AND** 被收合的子樹 MUST NOT 在可見節點之間留下空白欄位或列

#### Scenario: 收合展開往返不產生漂移

- **WHEN** 使用者對同一節點依序執行收合、展開、再收合
- **THEN** 第三步之後所有節點的座標 MUST 與第一步之後完全相同

#### Scenario: 隱藏節點不留舊世代座標

- **WHEN** 一張被判定為不健康的地圖在預設收合狀態下完成自動排版
- **THEN** 隱藏節點的座標 MUST 來自本次排版的推導結果
- **AND** MUST NOT 保留判定前的資料庫座標

### Requirement: 單一座標框架寫入

任何一次地圖儲存所送出的節點座標 SHALL 全部屬於同一個座標框架。系統 MUST NOT 送出「部分節點採自動排版結果、其餘節點採資料庫原值」的混合座標。

顯示座標來自自動排版而使用者尚未採用時，儲存 MUST 送出載入時保存的資料庫原始座標（影子副本），使非座標欄位（標題、屬性、關聯等）的編輯可以正常存檔而不改動座標。

框架升級 MUST 只由下列兩種明確意圖觸發：使用者實際拖動節點造成位移，或使用者按下「套用此排版」。系統 MUST 以「拖曳起點與終點座標不同」判定拖動，MUST NOT 以拖曳事件本身判定（節點拖曳門檻預設為 0，單擊亦會觸發拖曳結束事件）。升級後該次與後續儲存 MUST 整張送出畫面座標。

框架升級與「套用此排版」MUST 要求地圖更新權限；無權限者 MUST NOT 升級框架、MUST NOT 寫入座標，且畫布 MUST NOT 允許其拖動節點。「套用此排版」MUST 在展開全部節點的狀態下計算與寫入，並 MUST 在覆寫前把被覆寫的節點座標留存於稽核記錄。

#### Scenario: 未採用排版時的其他編輯不改動座標

- **WHEN** 一張以自動排版顯示的地圖上，使用者只修改了某節點的標題
- **THEN** 儲存後資料庫中所有節點的座標 MUST 與載入前完全相同

#### Scenario: 單擊節點不會固化排版

- **WHEN** 使用者在以自動排版顯示的地圖上點擊（按下並放開，未移動）某個節點
- **THEN** 系統 MUST NOT 升級座標框架
- **AND** MUST NOT 寫入任何座標

#### Scenario: 拖動節點後整張圖以新框架寫入

- **WHEN** 使用者在以自動排版顯示的地圖上把某節點拖到新位置
- **THEN** 該次儲存 MUST 送出全部節點的畫面座標
- **AND** MUST NOT 對其他節點送出資料庫原始座標

#### Scenario: 套用此排版需先展開並留存舊座標

- **WHEN** 使用者在收合狀態下按下「套用此排版」並確認
- **THEN** 系統 MUST 先展開全部節點、以整樹一致的排版計算座標後才寫入
- **AND** MUST 在稽核記錄中留存被覆寫的節點座標

#### Scenario: 唯讀使用者看得到正確排版但不會寫入

- **WHEN** 沒有地圖更新權限的使用者開啟一張被判定為不健康的地圖
- **THEN** 畫布 MUST 顯示自動排版結果
- **AND** 畫布 MUST NOT 允許拖動節點
- **AND** 系統 MUST NOT 寫入任何座標

### Requirement: 新節點與文字匯入的座標來源

新增節點時採用的相對位移 SHALL 對齊自動排版所使用的格線：水平位移 MUST 等於節點寬加上層距（275），垂直位移 MUST 等於節點高加上同層間距（150）。

文字匯入 MUST NOT 產生節點座標；匯入產生的節點座標 MUST 為 0，由畫布的排版權威決定顯示位置。

#### Scenario: 新增子節點不與父節點重疊

- **WHEN** 使用者為某節點新增一個子節點
- **THEN** 新節點的水平座標 MUST 為父節點水平座標加 275
- **AND** 新節點 MUST NOT 與父節點或既有兄弟節點的節點盒重疊

#### Scenario: 文字匯入的地圖由畫布決定排版

- **WHEN** 使用者以文字模式匯入一份不含座標資訊的地圖內容
- **THEN** 寫入資料庫的節點座標 MUST 全部為 0
- **AND** 該地圖在畫布上 MUST 以自動樹狀排版顯示

### Requirement: 顯示更新的終止性

畫布的收合狀態同步 SHALL 在有限次數內收斂。狀態同步 MUST NOT 因為每次都產生新的集合參考而自我觸發；當邊的顯示狀態沒有實際變化時，系統 MUST 回傳與先前相同的參考。

所有沿 `parent_id` 走訪祖先的邏輯（顯示狀態計算、排版可見性判定、子孫計數）MUST 對自環與循環父子關係安全終止。

#### Scenario: 載入後狀態同步收斂

- **WHEN** 使用者開啟任一非空地圖並靜置
- **THEN** 收合狀態同步的執行次數 MUST 在有限次內停止
- **AND** 畫布 MUST NOT 持續重建節點物件

#### Scenario: 動態加入的關聯邊仍取得顯示狀態

- **WHEN** 使用者觸發路徑高亮，於既有邊集合外動態加入關聯邊
- **THEN** 新加入的邊 MUST 依其兩端節點的隱藏狀態取得正確的顯示狀態

#### Scenario: 自環父節點不造成畫面凍結

- **WHEN** 地圖中存在 `parent_id` 指向自己的節點
- **THEN** 畫布 MUST 完成載入與渲染
- **AND** MUST NOT 進入無窮迴圈
